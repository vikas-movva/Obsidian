# Question 1
We want to show that the three versions of the Vertex Cover problem are **polynomial-time Turing equivalent**:
- **VC-D (Decision)**
- **VC-O (Optimization)**
- **VC-F (Function / Find a solution)**

To do this, we show the following reductions:
- VC-D ≤ VC-O
- VC-O ≤ VC-D
- VC-F ≤ VC-D
By transitivity, all three are equivalent.

---

## 1. Reducing VC-O to VC-D
Since `k` is between `0` and `|V|`, we can use **binary search**.

```python
function VC-O(G = (V, E)):
    lo ← 0
    hi ← |V|
    while lo < hi:
        mid ← ⌊(lo + hi) / 2⌋
        if VC-D(G, mid) = TRUE:
            hi ← mid
        else:
            lo ← mid + 1
    return lo
```

The predicate `VC_D(G, k)` is monotone so:
- If a vertex cover exists for size `k`, then it also exists for any `k' > k`.
Therefore binary search correctly finds the smallest valid `k`, which is the optimal solution.\

**Complexity**:
Binary search makes `O(log |V|)` calls to VC-D and is therefore polynomial

---

## 2. Reducing VC-D to VC-O

```python
function VC-D(G = (V, E), k):
    n* ← VC-O(G)
    return (n* ≤ k)
```

If we already know the minimum vertex cover size `k*`, then:
- There exists a cover of size ≤ `k` if and only if `k* ≤ k`

**Complexity**:
This function only has a single call to VC-O and is therefore polynomial

---

## 3. Reducing VC-F to VC-D
```python
function VC-F(G = (V, E)):
    k* ← 0
    lo ← 0,  hi ← |V|
    while lo < hi:
        mid ← ⌊(lo + hi) / 2⌋
        if VC-D(G, mid) = TRUE:
            hi ← mid
        else:
            lo ← mid + 1
    k* ← lo

    S        ← ∅
    H        ← G
    budget   ← k*

    for each vertex v ∈ V:
        if v ∉ V(H):
            continue
        H' ← H with v and all edges incident to v removed
        if VC-D(H', budget − 1) = TRUE:
            S      ← S ∪ {v}
            H      ← H'
            budget ← budget − 1
        else: do not add v
    return S
```

At every step, we are trying to build a valid minimum vertex cover of size `k*`.
For each vertex `v`:
- **If VC-D(H', budget - 1) is TRUE:**
    - Then we can include `v` in the solution
    - The remaining graph can still be covered within the remaining budget
    - So adding `v` is safe
- **If VC-D(H', budget - 1) is FALSE:**
    - Then no optimal solution includes `v`
    - So we skip it, and its neighbours must cover its edges later

# Question 2

## Problem 1: Clubs
To show Clubs is in NP, we need a polynomial-time verification algorithm.

Certificate: $S \subseteq {1,\dots, n}$

```python
Verify-Clubs(persons {1,…,n}, collection C, integer k, certificate S):
    if |S| > k:
        return FALSE
    for each club C_j ∈ C:
        found ← FALSE
        for each person p ∈ C_j:
            if p ∈ S:
                found ← TRUE
                break
        if found = FALSE:
            return FALSE
    return TRUE
```

The algorithm checks the size constraint: `|S| ≤ k` and if every club has at least one member in `S`

**Complexity**:
We have to check every club and every member inside it. Let `M = total number of memberships = Σ |C_j|`
`O(M·k) (or O(M) with a hash set)`
This is polynomial in the input size.

We can reduce from Vertex Cover, which is NP-complete.

**Reduction**:
We can convert a Vertex Cover instance into a Clubs instance.
```python
Reduce-VC-to-Clubs(G = (V,E), k):
    Persons ← V
    C       ← { {u, v} : (u,v) ∈ E }
    return (Persons, C, k)
```
Each vertex → person
Each edge → club of size 2

**Correctness**:
If VC has a solution

Suppose there is a vertex cover `S` with `|S| ≤ k`.
- Every edge `(u, v)` has at least one endpoint in `S`
- So each club `{u, v}` contains someone from `S`

Therefore, `S` is a valid Clubs solution.

If Clubs has a solution
Suppose there is a subset `S` with `|S| ≤ k` that hits every club.
- Every club `{u, v}` contains someone from `S`
- So for every edge `(u, v)`, at least one of `u` or `v` is in `S`

This is the same as vertex cover.

**Complexity**:
- One club per edge
- Total size: `O(|V| + |E|)`
- Reduction is linear → polynomial


Therefore Clubs ∈ NP and Vertex Cover ≤ₚ Clubs so, Clubs is NP-complete

## Problem 2: EvenSplit
To show EvenSplit is in NP, we need a polynomial-time verification algorithm.

Certificate: $S \subseteq {1,\dots,n}$
```python
Verify-EvenSplit(integers a_1,…,a_n, certificate S):
    sum_S    ← 0
    sum_comp ← 0
    for i = 1 to n:
        if i ∈ S:
            sum_S    ← sum_S    + a_i
        else:
            sum_comp ← sum_comp + a_i
    return (sum_S = sum_comp)
```

The algorithm checks whether the sum of elements in `S` is equal to the sum of elements not in `S`.

**Complexity**:
We do one pass over all `n` elements.
`O(n)` arithmetic operations (polynomial in input size).

---
We can reduce from Subset Sum, which is NP-complete.

**Reduction**:
We convert a Subset Sum instance into an EvenSplit instance.
```python
Reduce-SubsetSum-to-EvenSplit(b_1,…,b_m, T):
    B = sum of all b_i

    a_1,…,a_m = b_1,…,b_m
    a_{m+1} = T + 1
    a_{m+2} = B - T + 1

    return (a_1,…,a_{m+2})
```

We keep the original numbers and add two extra values to force the total sum to split evenly.

**Correctness**:
First compute total sum:
- $A = B + (T+1) + (B-T+1) = 2B + 2$
- Target for each side is $A/2 = B + 1$

Also note:
- $(T+1) + (B-T+1) = B + 2 > B+1$
    So both added numbers cannot be on the same side. They must be split.

If Subset Sum has a solution
Suppose there exists a subset `T` such that:
- $\sum_{i \in T} b_i = T$

Construct:
- `S = T ∪ {m+2}`

Then:
- $\text{sum}(S) = T + (B - T + 1) = B + 1$

So this is a valid EvenSplit solution.

---
If EvenSplit has a solution suppose there exists `S` such that sum is `B + 1`.

Exactly one of the two added elements is in `S`.
**Case 1:** $a_{m+2} \in S$
- $\sum(T) + (B - T + 1) = B + 1$
- $\Rightarrow \sum(T) = T$
So we get a valid Subset Sum solution.

**Case 2:** $a_{m+1} \in S$
- $\sum(T') + (T + 1) = B + 1$
- $\Rightarrow \sum(T') = B - T$
So the complement of `T'` sums to `T`, giving a valid solution.

**Complexity**:
- We add 2 numbers and compute a sum
- Time: `O(m)`
- Output size is linear
So the reduction is polynomial.

Therefore EvenSplit ∈ NP and Subset Sum ≤ₚ EvenSplit, so EvenSplit is NP-complete.

# Question 3
To show how the reduction works, we construct a Subset Sum instance from a 3-SAT formula.

## Construction
We have:
- `n = 3` variables → `x₁, x₂, x₃`
- `k = 4` clauses → `C₁, C₂, C₃, C₄`

Each number has `n + k = 7` digits arranged as:
⟨x₁, x₂, x₃ | C₁, C₂, C₃, C₄⟩

For each variable `xᵢ`:
- `yᵢ` → represents `xᵢ = TRUE`
- `zᵢ` → represents `xᵢ = FALSE`

We can:
- Put `1` in column `xᵢ`
- Put `1` in clause column if the literal appears in that clause

For each clause `Cⱼ`:
- Add two slack variables `sⱼ, s′ⱼ`
- Each has a `1` only in column `Cⱼ`

**Target**: $t = ⟨1,1,1 | 3,3,3,3⟩$

We can set the target to 3 because:
- Each clause gets contributions from chosen literals (1 to 3)
- We add slack values to reach exactly 3
- If a clause gets 0 (unsatisfied), we would need 3 slacks
- But only 2 exist → impossible

So only satisfying assignments can reach the target.


```
y₁ = 1 001 010
z₁ = 1 000 101

y₂ = 0 100 110
z₂ = 0 101 001

y₃ = 0 010 101
z₃ = 0 011 010

s₁ = 0 001 000
s′₁ = 0 001 000

s₂ = 0 000 100
s′₂ = 0 000 100

s₃ = 0 000 010
s′₃ = 0 000 010

s₄ = 0 000 001
s′₄ = 0 000 001

t  = 1 113 333
```

Digits are small, so no carries happen when adding.

3-SAT Certificate:
```id="fmt5"
x₁ = T, x₂ = T, x₃ = T
```

Check clauses:
- `C₁: x₁ ∨ ¬x₂ ∨ ¬x₃ = T`
- `C₂: ¬x₁ ∨ x₂ ∨ x₃ = T`
- `C₃: x₁ ∨ x₂ ∨ ¬x₃ = T`
- `C₄: ¬x₁ ∨ ¬x₂ ∨ x₃ = T`

Since all variables are TRUE, pick: $\{y₁, y₂, y₃\}$

Clause contributions:
```id="fmt7"
C₁: 1
C₂: 2
C₃: 2
C₄: 1
```

We need to reach 3 in each column, so add slacks:
```id="fmt8"
C₁: +2 → s₁, s′₁
C₂: +1 → s₂
C₃: +1 → s₃
C₄: +2 → s₄, s′₄
```

Final subset: $S = \{y₁, y₂, y₃, s₁, s′₁, s₂, s₃, s₄, s′₄\}$

**Verification**:
Column-wise sum:
```
x₁ x₂ x₃ | C₁ C₂ C₃ C₄
 1  1  1 |  3  3  3  3
```
This matches the target.

**Numeric check**:
```
  1 001 010
+   100 110
+    10 101
+     1 000
+     1 000
+       100
+        10
+         1
+         1
-----------
  1 113 333  ✓
```

A satisfying assignment for 3-SAT gives a valid subset and an unsatisfied clause cannot reach the target

So this reduction correctly maps 3-SAT to Subset Sum.

# Question 4
# 3-SAT → Independent Set Decision (ISD)

## The Reduction

The standard reduction from 3-SAT to ISD works as follows:

```python
Reduce-3SAT-to-ISD(phi with clauses C_1,...,C_k):
    V' ← empty
    E' ← empty
    for each clause C_j = (l_j1 ∨ l_j2 ∨ l_j3):
        add nodes (l_j1, j), (l_j2, j), (l_j3, j) to V'
    for each clause C_j:
        add edges (l_j1,j)-(l_j2,j), (l_j1,j)-(l_j3,j), (l_j2,j)-(l_j3,j) to E'
    for each pair of nodes (l_ja, j) and (l_ib, i) where i ≠ j:
        if l_ja and l_ib are complementary (e.g. x and ¬x):
            add edge (l_ja, j)-(l_ib, i) to E'

    k ← number of clauses
    return (G' = (V', E'), k)
```

**Key ideas:**

- Each clause becomes a **triangle** — you can pick at most one node per clause
- Conflict edges ensure you cannot pick **both** $x_i$ and $\neg x_i$
- An independent set of size $k$ = one true literal picked per clause = satisfying assignment

---

## The 3-SAT Instance

$(x_1 \lor \neg x_2 \lor \neg x_3) \land (\neg x_1 \lor x_2 \lor x_3) \land (x_1 \lor x_2 \lor \neg x_3) \land (\neg x_1 \lor \neg x_2 \lor x_3)$

Clauses:

|Clause|Literals|
|---|---|
|$C_1$|$x_1 \lor \neg x_2 \lor \neg x_3$|
|$C_2$|$\neg x_1 \lor x_2 \lor x_3$|
|$C_3$|$x_1 \lor x_2 \lor \neg x_3$|
|$C_4$|$\neg x_1 \lor \neg x_2 \lor x_3$|


## ISD Instance
We get $4 \times 3 = 12$ nodes, one per literal occurrence:

|Clause|Node 1|Node 2|Node 3|
|---|---|---|---|
|$C_1$|$(x_1, 1)$|$(\neg x_2, 1)$|$(\neg x_3, 1)$|
|$C_2$|$(\neg x_1, 2)$|$(x_2, 2)$|$(x_3, 2)$|
|$C_3$|$(x_1, 3)$|$(x_2, 3)$|$(\neg x_3, 3)$|
|$C_4$|$(\neg x_1, 4)$|$(\neg x_2, 4)$|$(x_3, 4)$|

Intra-clause edges:
$C_1: (x_1,1)\text{-}(\neg x_2,1),; (x_1,1)\text{-}(\neg x_3,1),; (\neg x_2,1)\text{-}(\neg x_3,1)$
$C_2: (\neg x_1,2)\text{-}(x_2,2),; (\neg x_1,2)\text{-}(x_3,2),; (x_2,2)\text{-}(x_3,2)$
$C_3: (x_1,3)\text{-}(x_2,3),; (x_1,3)\text{-}(\neg x_3,3),; (x_2,3)\text{-}(\neg x_3,3)$
$C_4: (\neg x_1,4)\text{-}(\neg x_2,4),; (\neg x_1,4)\text{-}(x_3,4),; (\neg x_2,4)\text{-}(x_3,4)$

Inter-clause conflict edges:
$x_1 \leftrightarrow \neg x_1:\quad (x_1,1)\text{-}(\neg x_1,2),; (x_1,1)\text{-}(\neg x_1,4),; (x_1,3)\text{-}(\neg x_1,2),; (x_1,3)\text{-}(\neg x_1,4)$
$x_2 \leftrightarrow \neg x_2:\quad (\neg x_2,1)\text{-}(x_2,2),; (\neg x_2,1)\text{-}(x_2,3),; (\neg x_2,4)\text{-}(x_2,2),; (\neg x_2,4)\text{-}(x_2,3)$
$x_3 \leftrightarrow \neg x_3:\quad (\neg x_3,1)\text{-}(x_3,2),; (\neg x_3,1)\text{-}(x_3,4),; (\neg x_3,3)\text{-}(x_3,2),; (\neg x_3,3)\text{-}(x_3,4)$

Target: $k = 4$

## 3-SAT Certificate
$x_1 = \text{T}$
$x_2 = \text{T}$
$x_3 = \text{T}$

| Clause                                 | Evaluation        | Satisfied |
| -------------------------------------- | ----------------- | :-------: |
| $C_1: x_1 \lor \neg x_2 \lor \neg x_3$ | $T \lor F \lor F$ |    Yes    |
| $C_2: \neg x_1 \lor x_2 \lor x_3$      | $F \lor T \lor T$ |    Yes    |
| $C_3: x_1 \lor x_2 \lor \neg x_3$      | $T \lor T \lor F$ |    Yes    |
| $C_4: \neg x_1 \lor \neg x_2 \lor x_3$ | $F \lor F \lor T$ |    Yes    |

All four clauses are satisfied.

## ISD Certificate
From the assignment, pick one true literal per clause as the representative node:

|Clause|True literal picked|Node selected|
|---|---|---|
|$C_1$|$x_1 = T$|$(x_1, 1)$|
|$C_2$|$x_2 = T$|$(x_2, 2)$|
|$C_3$|$x_1 = T$|$(x_1, 3)$|
|$C_4$|$x_3 = T$|$(x_3, 4)$|

$S = {(x_1,1),; (x_2,2),; (x_1,3),; (x_3,4)}$

Verification that $S$ is an Independent Set:
Check every pair in $S$ for edges:

| Pair                    | Same clause |       Complementary literals?        | Edge exists |
| ----------------------- | :---------: | :----------------------------------: | :---------: |
| $(x_1,1)$ and $(x_2,2)$ |     No      |       No ($x_1 \neq \neg x_2$)       |     No      |
| $(x_1,1)$ and $(x_1,3)$ |     No      | No (same literal, not complementary) |     No      |
| $(x_1,1)$ and $(x_3,4)$ |     No      |       No ($x_1 \neq \neg x_3$)       |     No      |
| $(x_2,2)$ and $(x_1,3)$ |     No      |       No ($x_2 \neq \neg x_1$)       |     No      |
| $(x_2,2)$ and $(x_3,4)$ |     No      |       No ($x_2 \neq \neg x_3$)       |     No      |
| $(x_1,3)$ and $(x_3,4)$ |     No      |       No ($x_1 \neq \neg x_3$)       |     No      |

No two nodes in $S$ are connected by an edge. Therefore $S$ is an independent set of size $|S| = 4 = k$.

If the 3-SAT instance is satisfiable, then picking one true literal per clause always gives an independent set of size $k$ because:
1. Intra-clause edges are avoided and we pick only one node per triangle
2. Conflict edges are avoided and we never pick both $x_i$ and $\neg x_i$, since an assignment makes at most one of them true
